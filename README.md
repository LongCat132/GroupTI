# GroupTI - 小组作业人格鉴定中心

一个荒诞但认真执行的小组作业人格测试。它把大学小组作业里的 DDL、群聊、分工、摆烂和兜底行为，包装成一套“事故档案系统”，给用户生成专属 GroupTI 人格特质。

在线访问: https://longcat132.github.io/GroupTI/

## 项目简介

GroupTI (Group Team Indicator) 是一个 MBTI 风格的趣味单页应用。用户先选择自己通常是组长还是组员，再回答 15 道小组作业场景题，最终得到 16 种人格类型之一。

当前产品气质是“搞怪中带着一丝荒诞”：页面像一套过分严肃的小组作业事故鉴定系统，结果页会生成类似事故档案的人格报告，并支持匹配预测、结果图片和数据统计。

## 当前功能

- 角色分流：组长 / 组员两套结果文案。
- 15 道题：10 道基础题 + 5 道角色专属题。
- 4 个二元维度：生成 `CVRI`、`DVEG` 等 16 种人格特质。
- 多维权重计分：每个选项可同时影响主倾向和辅助倾向。
- 计分校准：通过模拟脚本检查并缓解结果分布偏斜。
- 事故档案 UI：欢迎页、题目页、结果页、匹配区都采用“鉴定报告”语气。
- 结果页：人格特质、样本编号、典型症状、高发案发现场、组队建议。
- 组队事故预测：输入对方人格特质，生成存活率和事故等级。
- 人格图鉴：展示 16 种人格的趣味名和严格定义。
- 分享体验：复制类型、分享文案、生成结果图片。
- 数据收集：通过 Google Apps Script 写入 Google Sheet。
- 本地统计页：导入 Sheet 导出的 CSV，查看人格排行、角色分布、维度分布。
- 调试入口：测试时可跳过数据收集，避免污染统计。

## 核心维度

| 维度 | 字母 | 含义 |
|------|------|------|
| 时间态度 | C / D | Control 掌控时间 vs Deadline 放养时间 |
| 沟通方式 | V / S | Vocal 话痨沟通 vs Silent 沉默潜水 |
| 决策风格 | R / E | Result 结果导向 vs Emotion 情感导向 |
| 执行偏好 | I / G | Idea 创意型 vs Grunt 执行型 |

## 题目结构

### 基础题目 (10 题)

1. 离展示还有 3 天，组内进度 50%
2. 你的 part 被打回重做 3 次
3. 小组讨论时的角色
4. 看到组员发“收到”但 24 小时没动静
5. 分配任务时的倾向
6. 面对分歧时
7. 当有人说“这个我不会”
8. 小组作业截止前 24 小时
9. 完成作业后
10. 收到群里 99+ 消息

### 角色专属题目 (5 题)

组长题目：

1. 刚被选为组长
2. 组员说“不想做”
3. 看到组员进度慢
4. 展示前一周
5. 组员做出了成果

组员题目：

1. 被分配到不想做的部分
2. 组长催进度时
3. 做作业时喜欢的方式
4. 组长提出新想法
5. 其他组员摆烂

## 数据收集

项目使用 Google Apps Script + Google Sheets 收集匿名测试结果。完成测试后会提交：

- 人格类型
- 用户角色
- 15 道题答案
- 每题权重详情
- 四个维度得分
- 页面 URL
- 浏览器信息
- 客户端完成时间

详细说明见 [DATA_COLLECTION.md](./DATA_COLLECTION.md)。

### 调试入口

这些入口不会写入 Google Sheet：

```text
index.html?debug=1
index.html?test=1
index.html#debug
```

这个入口会写入 Google Sheet，但标记为调试数据：

```text
index.html?debug=collect
```

统计页会默认排除调试数据。

## 本地运行

直接打开也可以：

```bash
open index.html
```

推荐用本地 HTTP 服务，便于测试浏览器能力和相对路径：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080/
```

## 数据统计

从 Google Sheet 下载 CSV 后，可以打开本地统计页：

```text
stats.html
```

统计页支持：

- 有效记录数
- 调试记录数
- 人格类型排行
- 组长 / 组员比例
- 四个维度分布
- 最近记录列表

## 分布模拟

用于检查题库和权重是否导致某些人格过度集中：

```bash
node tools/simulate-distribution.js 5000
```

脚本会分别模拟组长和组员结果，输出 16 种类型分布和 8 个维度字母比例。

## 技术栈

- 单文件主应用：HTML + CSS + JavaScript
- 数据收集：Google Apps Script + Google Sheets
- 本地分析：独立 `stats.html`
- 分布校验：Node.js 脚本
- 部署：GitHub Pages

## 部署

### GitHub Pages

1. 推送到 GitHub 仓库。
2. 进入 Settings -> Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`。
5. 访问 `https://longcat132.github.io/GroupTI/`。

### Netlify Drop

1. 打开 https://app.netlify.com/drop
2. 拖拽 `index.html`
3. 得到分享链接

如果使用 Netlify Drop，只部署 `index.html` 会丢失 `stats.html` 和脚本文件；正式部署仍建议使用 GitHub Pages。
